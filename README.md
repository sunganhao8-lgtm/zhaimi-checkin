# 宅咪打卡 🐾

> 别让毛孩子白等一天 —— 养宠打卡 + 周报成绩单

宅域（Zhaiyu）旗下的 C 端产品。先用线上打卡工具建立用户群，门店落地后成为线下核销与服务节点。

## 产品逻辑（Guilt Loop）

```
每日打卡(喂食/遛狗/铲屎…)
   ↓
连续天数 🔥 streak（断卡有损失感）
   ↓
周期任务倒计时（疫苗/驱虫/洗澡，超期红字内疚提示）
   ↓
周报卡（Canvas 生成 3:4 分享图 → 朋友圈/小红书裂变）
```

参考模式：Quittr（戒色打卡，4 个月 $25 万/月）、Early（闹钟，$5 万/月）——
**羞耻/内疚赛道 + streak 机制 + 可晒成绩单**，宠物垂直国内暂无对标。

## 当前功能（MVP · 纯前端）

- 多宠物档案（猫/狗/其他，emoji 或照片头像，照片压缩至 128px 存 localStorage）
- 每日打卡：喂食/加水/铲屎/遛狗(仅犬)/陪玩，按宠物类型适配
- 连续天数：以"喂食"为底线；今天未喂不断签但展示内疚横幅
- 周期任务：驱虫 30 天 / 洗澡 14 天 / 疫苗 365 天 / 体重 7 天，自动算下次到期，超期红色警告
- 体重记录 + 趋势（▲▼）
- 周报卡：1080×1440 Canvas，奶油底 + 橙红点缀 + 爪印水印 + 7 日格子，长按保存
- 数据导出/导入 JSON（不锁用户数据）
- 演示模式：URL 加 `?demo=1`（预置虚拟猫"糯米"+ 7 天历史）
- **PWA 可安装**：手机浏览器"添加到主屏幕"后全屏独立运行，Service Worker 离线缓存
- 周报卡浮层支持"保存图片"按钮（电脑端），手机长按保存
- **打卡月历热力图**：整月完成度一屏可见（4 级色深 + 今日描边 + 翻月），月完成率只统计已过日子
