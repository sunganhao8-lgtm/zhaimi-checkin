# 宅咪打卡 🐾

> 别让毛孩子白等一天 —— 养宠打卡 + 周报成绩单

宅域（Zhaiyu）旗下的 C 端产品。先用线上打卡工具建立用户群，门店落地后成为线下核销与服务节点。

## 产品逻辑（Guilt Loop）

```
每日打卡(喂食/遛狗/铲屎…)
   ↓
连续天数 🔥 streak（断卡有损失感）
   ↓
周期任务倒计时（疫苗/驱虫/洗澡，超期红字内疚提示）
   ↓
周报卡（Canvas 生成 3:4 分享图 → 朋友圈/小红书裂变）
```

参考模式：Quittr（戒色打卡，4 个月 $25 万/月）、Early（闹钟，$5 万/月）——
**羞耻/内疚赛道 + streak 机制 + 可晒成绩单**，宠物垂直国内暂无对标。

## 当前功能（MVP · 纯前端）

- 多宠物档案（猫/狗/其他，emoji 或照片头像，照片压缩至 128px 存 localStorage）
- 每日打卡：喂食/加水/铲屎/遛狗(仅犬)/陪玩，按宠物类型适配
- 连续天数：以"喂食"为底线；今天未喂不断签但展示内疚横幅
- 周期任务：驱虫 30 天 / 洗澡 14 天 / 疫苗 365 天 / 体重 7 天，自动算下次到期，超期红色警告
- 体重记录 + 趋势（▲▼）
- 周报卡：1080×1440 Canvas，奶油底 + 橙红点缀 + 爪印水印 + 7 日格子，长按保存
- 数据导出/导入 JSON（不锁用户数据）
- 演示模式：URL 加 `?demo=1`（预置虚拟猫"糯米"+ 7 天历史）

## 运行

```bash
cd zhaimi-checkin
python -m http.server 8123
# 手机同局域网访问 http://<本机IP>:8123/?demo=1
```

测试：`node test-logic.js`（14 项断言：streak/周统计/周期/体重）

## 发布选项

| 方案 | 优点 | 缺点 |
|---|---|---|
| GitHub Pages | 零成本，立即可发 | 国内访问慢 |
| 小米 NAS + cpolar | 国内快，已有设备 | 需保持开机 |
| 微信小程序 | 原生分享、群裂变 | 需注册审核（建议验证跑通后再移植） |

## 路线图

- **P0（当前）**：纯前端 MVP，种子用户验证留存
- **P1**：接后端（云函数即可）+ AI 周报点评（本地 Qwen 或 API），周报卡加 AI 语音/文案
- **P2**：移植微信小程序（逻辑层 `calcStreak/calcWeekStats/periodicStatus` 可直接复用，UI 层改 wxml）
- **P3**：病历/体检报告拍照归档（垂直记忆，躲开通用日记红海）→ 就诊一键给医生
- **P4**：宅域门店打通——周报卡兑换洗护券，线上养成反哺线下

## 观测指标（种子期只看三个）

1. 次日留存（打卡这个动作天然日活，看有没有人真用）
2. 周报卡生成率/分享率（裂变核心）
3. 连续 7 天以上的用户占比（streak 机制是否成立）

## 技术栈

无框架、无依赖、无构建。index.html + style.css + app.js（~450 行）。
Canvas 周报卡、localStorage 持久化、FileReader 照片压缩。
